# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately, using either of these:

1. **GitHub private reporting (preferred):** open the repository's *Security* tab and choose *Report a vulnerability*.
2. **Email:** security@cocan.dev

Please include what you found, the version or commit, the steps to reproduce it, and what you think the impact is. Do not include secrets such as API keys in your report.

## What to expect

- We acknowledge your report within **seven days**.
- We tell you whether we consider it a vulnerability, and keep you updated until it is fixed.
- We agree a date with you before anything is made public, and we credit you if you wish.
- We will not take legal action against good-faith research that follows this policy.

## Supported versions

kirpitch has no release yet. Until the first release, only the latest commit on the `main` branch is supported. This section will list supported versions once there are releases.

## Scope

In scope: the kirpitch code in this repository and how it handles files, settings and credentials on your machine.

Out of scope: KiCad itself, language-model providers and their services, and the operating system. Please report problems there to their own projects.
